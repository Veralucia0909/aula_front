# 📚 Conteúdos estudados

## ⚛️ React

React é uma biblioteca JavaScript utilizada para construção de interfaces de usuário.

Um dos principais conceitos trabalhados é a **componentização**, permitindo dividir uma aplicação em pequenas partes reutilizáveis.

### Principais conceitos

* ⚛️ Componentes
* 🧩 Componentização
* JSX
* 📦 Props
* 🔄 State
* 🪝 Hooks
* 🌐 Context API
* 🔗 Integração com APIs
* 🧭 React Router
* 📱 Single Page Applications — SPA
* ♻️ Reutilização de código

### Métodos HTTP

| Método    | Função             |
| --------- | ------------------ |
| 🟢 GET    | Buscar dados       |
| 🔵 POST   | Criar/enviar dados |
| 🟡 PUT    | Atualizar dados    |
| 🟡 PATCH  | Atualizar dados    |
| 🔴 DELETE | Remover dados      |

### Ferramentas

* Fetch API
* Axios
* Estados de carregamento
* Tratamento de erros
* Dados recebidos

# 📱 SPA — Single Page Application

As **SPAs** permitem atualizar partes da aplicação sem recarregar toda a página.

### Benefícios

* ⚡ Navegação mais rápida
* 🔄 Atualização dinâmica
* 🚫 Menos recarregamentos
* 📱 Experiência mais fluida
* 🧩 Integração com componentes React
